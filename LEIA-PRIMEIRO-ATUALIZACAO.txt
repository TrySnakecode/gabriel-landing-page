2. Envie TODO O CONTEÚDO da pasta ao repositório GitHub Pages, na raiz.
3. Commit changes; aguarde a atualização do GitHub Pages.
4. Após a publicação, recarregue com Ctrl+F5.
5. Faça um envio REAL de teste pelo site publicado (não pelo arquivo file://).
6. No painel FormSubmit.io, confirme a conta, o domínio (se for solicitado) e o recebimento.
