# Fotografias reais — fontes e licenças

Esta versão troca as imagens mais artificiais por fotografias reais de referência, servidas
pelo CDN oficial do Pexels (images.pexels.com) em larguras de até 2200 px.

IMPORTANTE: o site PRECISA de internet para carregar estas fotografias. Devido a uma
limitação de acesso externo no ambiente de edição, os arquivos originais não puderam
ser embutidos no ZIP; as imagens locais anteriores foram mantidas como fallback offline.

Para ter um projeto totalmente independente do Pexels, faça o download de cada foto nos
links de origem abaixo e coloque-a em assets/img, ajustando as URLs nos HTML/JS.

Estas fotografias são REFERÊNCIAS VISUAIS e não representam obras executadas pelas
marcas conceituais Bruma, Alva, Prumo e Risco. Em especial, os ambientes Casa Pátio
são fotografias de casas diferentes; a galeria é uma coleção de inspirações, não um
registro coerente de uma residência real construída.

A comparação dia/anoitecer do Refúgio Neblina permanece como visualização conceitual
para não simular que duas residências distintas sejam um só projeto.

Licença Pexels: https://www.pexels.com/license/
As fotografias podem ser utilizadas em sites, inclusive comerciais, sem crédito
obrigatório, respeitadas as condições específicas sobre marcas/pessoas.
